CDN 基础（内容分发网络）

① DNS 智能调度选出离用户最近的节点；② 请求边缘节点； ③ 缓存命中直接返回；④⑤ 未命中回源拉取、写入缓存再返回。 本质：用「空间换时间」。

01工作流程

  • ① DNS 调度：业务域名 CNAME 到 CDN 厂商的调度域；GSLB 根据 Local DNS 出口 IP 判断地理位置 + 运营商 + 节点负载，返回最优边缘节点 IP（上海用户 → 上海节点）
  • ② 请求边缘节点：上海用户直连同城的上海节点，不再跨大半个中国访问深圳源站
  • ③ 缓存命中：节点直接返回内容，延迟从几百 ms 降到几十 ms
  • ④ 未命中 / 过期：边缘节点回源拉取（实际中常经 父节点/区域节点 多级缓存，层层挡回源）
  • ⑤ 写入缓存再返回：后续用户全部命中，源站压力被边缘节点挡掉
  • 一句话：第一个用户慢，之后都快；源站看到的流量只剩回源流量
